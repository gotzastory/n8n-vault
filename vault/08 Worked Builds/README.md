# 08 Worked Builds (public skeleton)

โฟลเดอร์นี้ใน **เครื่อง Got** เก็บ note workflow จริง (gitignored)

ใน **repo สาธารณะ** มีแค่:
- กติกา → ดู [[CASE FOLDERS]] ที่รากคลัง
- ตัวอย่างสมมติ → [[Workflow - Example Sample]]

## ของคุณเอง
1. คัดลอก `_templates/Template - n8n Workflow.md`
2. วางที่นี่ (เดี่ยว) หรือ `08/<Case Name>/` + `00 Case.md`
3. ใส่ `workflow_id` หลัง build บน instance คุณ
4. อัปเดต `INDEX.md` (ใช้ `INDEX.example.md` เป็นต้นแบบ)
